rokey1 실행 순서

터미널 준비 → 웹 HMI에서 액션 서버 켜기 → 탐색 → 틈 하나씩 퍼티·샌딩 → 전체 공정. 체크 박스는 이 브라우저에만 저장됩니다.

실제 로봇을 움직이기 전에bringup의 mode, 웹의 모드 버튼, 액션 서버를 켤 때의 모드가 모두 같아야 합니다. 처음 실행은 속도 30~50%, 하드웨어 비상정지 버튼을 손 닿는 곳에 두세요. 웹의 비상 정지는 소프트웨어 정지일 뿐입니다.

A터미널 준비 (서버 PC)

  1. 빌드 — 모든 팀원 PC에서 한 번

    액션 메시지(Process.action)에 wall 필드가 추가됐습니다. 한 PC라도 옛 빌드면 액션 통신이 안 됩니다.

    cd ~/ws_cobot_pjt/ws_dsr
colcon build --packages-select rokey_interfaces rokey1
source install/setup.bash

  2. DB 접속 확인

    접속 정보는 config/robot.yaml의 db 섹션입니다.

    mysql -u cobot -pcobot cobot -e "SHOW TABLES;"   # run, wall, gap, task_log, quality

  3. 로봇 bringup

    # 가상 (에뮬레이터)
ros2 launch dsr_bringup2 dsr_bringup2_rviz.launch.py mode:=virtual host:=127.0.0.1 port:=12345 model:=m0609
# 실제 로봇이면 mode:=real 과 컨트롤러 IP

  4. 웹 HMI 서버

    ros2 launch rokey1 process.launch.py host:=0.0.0.0     # 다른 PC에서도 접속
# 로봇 없이 DB 흐름만: ros2 launch rokey1 process.launch.py fake:=true

    브라우저 주소: http://<서버 PC IP>:8080

B웹 HMI에서

  1. 연결 상태 보기

    맨 위 연결 칩이 초록인지, 통신 모듈의 두산 서비스가 연결이고 /joint_states가 0 Hz가 아닌지 봅니다.

  2. 모드와 속도

    작업 실행 모듈 아래 모드를 bringup과 같게(가상 / 실제) 고릅니다. 속도 슬라이더는 처음엔 30~50%.

  3. 액션 서버 3개 켜기 (모드를 정한 뒤에)

    각 탭에서 선택하고 ▶ 시작. 끝나는 작업이 아니라 계속 켜 두는 서버입니다. 서버는 켤 때의 모드로 동작하므로, 모드를 바꿨으면 정지 후 다시 켭니다.

    탭작업로그에 나오면 준비 완료
    벽면 탐색탐색 액션 서버/process/explore 준비
    퍼티퍼티 액션 서버퍼티 액션 준비
    샌딩샌딩 액션 서버goal 대기 로그 (RG2 /onrobot 필요)

  4. 탐색

    공정 탭 → 탐색 → 아래 파라미터 입력 → ▶ 시작. 로봇이 바닥 → 벽 → 높이 → 너비를 찍어서 잽니다. 실시간 작업 현황 탭에서 로그를 봅니다.

    끝나면 로그에 wall_id=… · gap_id=[…]가 찍힙니다. 이 gap_id를 적어 두세요. 비어 있으면 robot.yaml의 explore.gaps에 틈 좌표를 넣고 다시 탐색합니다(틈 자동 감지는 아직 없음).

  5. 틈 하나로 퍼티 → 샌딩

    공정 → 퍼티 → 틈 번호 (gap_id)에 위 번호 → 시작. 끝나면 같은 번호로 샌딩. 샌딩은 그 틈의 벽 4점으로 벽 방향을 계산하고, 누르는 힘은 robot.yaml force.sanding.press_force 값을 씁니다.

  6. 전체 공정

    공정 → 전체 공정. 탐색 → 틈마다 퍼티 → 틈마다 샌딩 순서로, 실패하면 그 자리에서 멈춥니다(재시도 없음).

  7. 결과 보기 · 멈추기

    실행 기록에 결과(OK / STOP / E_xxx)가 남습니다. 멈출 땐 상단의 ■ 전체 정지, 위험하면 비상 정지(Esc) → 원인 해결 후 RESET.

C공정 파라미터 넣는 법

항목쓰는 작업넣는 값
틈 번호 (gap_id)퍼티, 샌딩탐색 로그의 gap_id=[…] 중 하나 (1 이상 정수). 빈 칸으로 시작하며 새로고침하면 다시 비워집니다 — 매번 입력필수
목적4개 공정 모두TEST 시험 · EXPERIMENT 데이터 수집 · DEMO 시연. 분석할 때 이걸로 거릅니다기본값 있음
재료4개 공정 모두clay / putty — 실제로 쓴 재료기본값 있음
메모4개 공정 모두바꾼 조건 등 (예: press 15N). 200자까지 입력됩니다선택 입력

숫자 칸은 칸 아래 설명에 범위(예: 1 이상 · 정수)가 나오고, 비우거나 범위를 벗어나면 시작할 때 어느 칸이 왜 틀렸는지 알려 주고 실행하지 않습니다. 액션 서버와 화면 모드가 다르면 공정 시작이 막힙니다. 파라미터 영역 오른쪽 위 ↺ 기본값으로 버튼으로 되돌릴 수 있고, 기본값에서 바뀐 칸은 강조 표시됩니다. 틈 번호 외의 입력값은 브라우저에 저장돼 다음에도 남아 있습니다.
