# 개선 상황 

1. 각 벽을 객체화 하고 상하좌우로 움직이게 한다.
2. 각 벽의 8선분을 깍을 수 있게 한다.
3. 위 작업을 파라미터로 보낼 수 있게 한다.


# 최종 벽 (wall_f) — 위 개선 사항 1~3 반영

벽 F 불러오기 (기본값: wall3 형태 + 8모서리 2cm 모따기, 슬라이더로 패널 상하좌우 이동)
ros2 launch urdf_tutorial display.launch.py model:=/home/rokey/rokey_team_ai_workspace/협동-1_ROS2_자동화공정/model/wall_f.urdf

파라미터 바꿔서 wall_f.urdf 다시 생성
python3 wall_f_gen.py --chamfer 0.03
python3 wall_f_gen.py --set ul.front_top=0.05 --set lr.back=0 --set ll.dz=0.1

파라미터 넣어서 바로 RViz로 띄우기 (wall_f.urdf는 건드리지 않음)
ros2 launch ./wall_f_rviz.launch.py set:="ul.front_top=0.08 ll.dz=0.1"

- 패널: ul(상단 왼쪽) ur(상단 오른쪽) ll(하단 왼쪽) lr(하단 오른쪽), all(전체)
- 모서리 8개: front_/back_ + top/bottom/left/right (앞면 = -y), front/back 으로 한 면 4개를 한 번에 설정
- 위치: dx(좌우) dy(앞뒤) dz(상하) → 기본 위치에 더해짐, 슬라이더는 그 위치 기준 ±1m
- 전역: groove, step, split_height, thickness, total_width, total_height, wall_xyz 등 (--dump-params 로 전체 확인)
  1. 값을 넣는 세 가지 방법

  ┌───────┬────────────────────────┬───────────────┐
  │ 방법  │        사용 예         │     결과      │
  ├───────┼────────────────────────┼───────────────┤
  │ --set │ python3 wall_f_gen.py  │ wall_f.urdf를 │
  │  인자 │ --set                  │  다시 생성    │
  │       │ ul.front_top=0.05      │               │
  ├───────┼────────────────────────┼───────────────┤
  │ JSON  │ python3 wall_f_gen.py  │ wall_f.urdf를 │
  │ 파일  │ --params my_wall.json  │  다시 생성    │
  ├───────┼────────────────────────┼───────────────┤
  │ launc │ ros2 launch ./wall_f_r │ 바로 RViz로   │
  │ h     │ viz.launch.py set:="ul │ 띄움 (wall_f. │
  │ 인자  │ .front_top=0.05"       │ urdf는 바뀌지 │
  │       │                        │  않음)        │
  └───────┴────────────────────────┴───────────────┘

  세 가지를 같이 쓰면 기본값 → JSON → --chamfer → --set
  순서로 적용됩니다. 뒤에 적용된 값이 앞의 값을
  덮어씁니다.

  지금 적용된 전체 값은 아래 명령으로 볼 수 있습니다. 이
  명령은 wall_f.urdf도 다시 생성합니다.
  python3 wall_f_gen.py --dump-params

  ---

  2. --set 문법

  형식은 대상.항목=값입니다. 단위는 모두 m입니다.

  대상 (패널)

  ul = 상단 왼쪽    ur = 상단 오른쪽
  ll = 하단 왼쪽    lr = 하단 오른쪽
  all = 4개 패널 전부

  항목 ① 모따기: 모서리 하나씩

  앞면은 -y 면입니다.
  front_top    front_bottom    front_left    front_right
  back_top     back_bottom     back_left     back_right
  --set ul.front_top=0.05        # 상단 왼쪽 패널의 앞면
  윗모서리만 5cm
  --set lr.back_right=0.03       # 하단 오른쪽 패널의 
  뒷면 오른쪽 모서리만 3cm

  항목 ② 모따기: 여러 모서리를 한 번에

  --set ul.chamfer=0.04          # ul 패널 8모서리 전부 
  4cm
  --set ll.front=0.05            # ll 패널 앞면 
  4모서리를 5cm로
  --set all.back=0               # 모든 패널 뒷면 모따기
  제거
  --chamfer 0.03                 # = --set 
  all.chamfer=0.03

  항목 ③ 위치 오프셋

  기본 위치에 더해지는 값입니다.
  dx = 좌우 (+ 오른쪽)
  dy = 앞뒤 (+ 뒤쪽)
  dz = 상하 (+ 위쪽)
  --set ur.dz=0.2                # 상단 오른쪽 패널을 
  20cm 위로
  --set ll.dx=-0.1               # 하단 왼쪽 패널을 10cm
  왼쪽으로
  --set lr.dy=0.03               # 하단 오른쪽 패널만 
  3cm 더 뒤로 (단차를 따로 줌)

  항목 ④ 전역 파라미터

  대상 없이 이름만 씁니다.

  ┌──────────────┬─────────┬─────────────────────────┐
  │     이름     │ 기본값  │          의미           │
  ├──────────────┼─────────┼─────────────────────────┤
  │ total_width  │ 5.0     │ 벽 전체 가로            │
  ├──────────────┼─────────┼─────────────────────────┤
  │ total_height │ 2.0     │ 벽 전체 높이            │
  ├──────────────┼─────────┼─────────────────────────┤
  │ thickness    │ 0.2     │ 벽 두께                 │
  ├──────────────┼─────────┼─────────────────────────┤
  │ groove       │ 0.005   │ 좌/우 패널 사이 세로 홈 │
  │              │         │  폭                     │
  ├──────────────┼─────────┼─────────────────────────┤
  │              │         │ 하단 패널 높이 (상단    │
  │ split_height │ 1.0     │ 높이 = 전체 높이 − 이   │
  │              │         │ 값)                     │
  ├──────────────┼─────────┼─────────────────────────┤
  │ step         │ 0.05    │ 하단 패널의 y 단차      │
  ├──────────────┼─────────┼─────────────────────────┤
  │ move_limit_x │ 1.0     │ 좌우 슬라이더 범위 (±)  │
  ├──────────────┼─────────┼─────────────────────────┤
  │ move_limit_z │ 1.0     │ 상하 슬라이더 범위 (±)  │
  ├──────────────┼─────────┼─────────────────────────┤
  │ wall_xyz     │ [2,0,0] │ 월드 기준 벽 위치       │
  ├──────────────┼─────────┼─────────────────────────┤
  │ wall_rpy     │ [0,0,0] │ 월드 기준 벽 회전 (rad) │
  ├──────────────┼─────────┼─────────────────────────┤
  │ mass_total   │ 100     │ 전체 질량. 부피 비율로  │
  │              │         │ 패널에 나눠짐           │
  └──────────────┴─────────┴─────────────────────────┘

  --set groove=0.01 --set step=0.08 --set
  split_height=0.8
  --set wall_xyz=[1.5,0.3,0] --set wall_rpy=[0,0,1.5708]
    # 대괄호 안에 공백을 넣지 마세요

  3. JSON 파일로 관리하기

  값이 많거나 여러 배치를 저장해 두고 싶으면 JSON 파일이
  편합니다. 바꾸고 싶은 값만 적으면 되고, 나머지는
  기본값이 쓰입니다.

  my_wall.json
  {
    "groove": 0.01,
    "step": 0.08,
    "wall_xyz": [1.5, 0.0, 0.0],
    "panels": {
      "ul": { "dz": 0.05,
              "chamfer": { "front_top": 0.06,
  "front_left": 0.03 } },
      "lr": { "dx": 0.02, "dy": 0.01,
              "chamfer": { "back_bottom": 0.0,
  "back_right": 0.0 } }
    }
  }
  python3 wall_f_gen.py --params my_wall.json
  ros2 launch ./wall_f_rviz.launch.py
  params:=$PWD/my_wall.json

  --set과 같이 쓰면 JSON 값 위에 --set 값이
  덮어씌워집니다.
  python3 wall_f_gen.py --params my_wall.json --set
  ul.front_top=0.1

  4. RViz 슬라이더로 실시간 이동

  display.launch.py나 wall_f_rviz.launch.py로 띄우면
  Joint State Publisher 창에 슬라이더 8개가 나옵니다.

  ul_x_joint / ul_z_joint   ← 상단 왼쪽 좌우 / 상하
  ur_x_joint / ur_z_joint
  ll_x_joint / ll_z_joint
  lr_x_joint / lr_z_joint
  - 슬라이더 0은 기본 위치 + dx/dz를 적용한 위치입니다.
  - 슬라이더 범위는 move_limit_x, move_limit_z로
    바꿉니다.
  - Center 버튼을 누르면 모든 슬라이더가 0으로
    돌아갑니다.
  - 슬라이더로 움직인 결과는 저장되지 않습니다. 원하는
    위치를 찾았으면 그 값을 dx/dz에 넣고 URDF를 다시
    생성하세요.

  ---

  5. 값의 제한 (어기면 생성할 때 에러)

  - 모따기 값은 0 이상이어야 합니다.
  - 같은 쪽의 front_X와 back_X를 더한 값은 두께보다 
    작아야 합니다. 기본 두께 0.2이면 합이 0.2 미만이어야
    합니다.
    ValueError: front_top + back_top = 0.25 가 두께 0.2 
    이상입니다.
  - 모따기 하나의 크기는 패널의 가로와 높이 중 작은 쪽의
    절반보다 작아야 합니다.
  - split_height를 바꾸면 상단과 하단 패널의 높이가
    달라지므로 모따기 한도도 같이 달라집니다.

  6. 자주 쓰는 조합 예시

  # wall3와 똑같이 (모따기 없음)
  python3 wall_f_gen.py --chamfer 0

  # 로봇이 작업하는 앞면만 모따기, 뒷면은 그대로
  python3 wall_f_gen.py --set all.front=0.03 --set
  all.back=0

  # 가운데 홈 쪽 모서리만 크게 깎기 (V자 홈 형태)
  python3 wall_f_gen.py --chamfer 0 \
    --set ul.front_right=0.04 --set ll.front_right=0.04
  \
    --set ur.front_left=0.04  --set lr.front_left=0.04

  # 상하 단차 쪽 모서리만 깎기
  python3 wall_f_gen.py --chamfer 0 \
    --set ul.front_bottom=0.03 --set
  ur.front_bottom=0.03 \
    --set ll.front_top=0.03    --set lr.front_top=0.03

  # 저장하지 않고 바로 확인만
  ros2 launch ./wall_f_rviz.launch.py
  set:="all.chamfer=0 all.front=0.04 ur.dz=0.1"

  --set이나 params로 바꾼 값을 display.launch.py에서
  보려면 python3 wall_f_gen.py ...를 먼저 실행해서
  wall_f.urdf를 다시 생성해야 합니다.
  wall_f_rviz.launch.py는 실행할 때마다 새로 생성하므로
  이 과정이 필요 없습니다.
