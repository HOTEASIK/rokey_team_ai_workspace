# 모델 계획 (train.py 수정)

수정본: `files/rokey1/analysis/train.py` (원본 `work/files/rokey1/analysis/train.py`는 그대로 둠)

## 1. 원본의 문제

| 문제 | 이유 |
|---|---|
| 성공(0/1)만 예측 | 27회면 대부분 성공 → 실패가 없으면 학습 불가 |
| 로지스틱 계수 그대로 비교 | target_fz(약 -10)와 length_mm(약 100)는 크기가 달라 비교가 안 된다 |
| 입력에 `length_mm` | 실험은 같은 틈을 쓰므로 값이 하나 → 정보 없음 |
| 결정트리만 있음 | 조합 9개에서는 경계만 찾고 최적값을 못 준다 |
| 검증 없음 | 모델이 맞는지 알 수 없다 |

## 2. 바꾼 것

| # | 출력 | 예측 대상 | 모델 | 조건 |
|---|---|---|---|---|
| 1 | 조합별 표 | — | SQL GROUP BY | 그대로 |
| 2 | **최적 조합 (주 모델)** | `contact_ratio` (자동, 연속값) | 2차 회귀(반응표면) `fz, vel, fz², vel², fz·vel` | 10개 이상 |
| 3 | 성공 확률 | `success` | 표준화 + 로지스틱 회귀 | 성공·실패 각 3개 이상 |
| 4 | 발표용 규칙 | `quality.score` | 결정트리 depth 2 | 5개 이상 |

- 입력은 `target_fz`, `vel` 2개. `length_mm`는 뺐다(틈 모양은 나중에 따로 실험).
- 최적 조합: 실험한 범위 안을 11×11 격자로 나눠 예측값이 가장 큰 점을 고른다.
- 검증: LOO 교차검증 R². 0보다 커야 평균으로 찍는 것보다 낫다.

## 3. 실험 방법

1. 목표 힘 3단계 × 속도 3단계 × 3회 = 27회, 아이클레이, **순서는 섞는다** (도구 마모·재료 굳음 영향 분산).
2. 틈은 같은 종류로 고정한다.
3. `python3 ~/ws_cobot_pjt/ws_dsr/src/rokey1/analysis/train.py putty_scrape clay`
4. 2)의 최적 조합을 `robot.yaml`에 넣고 3~5회 실행 → 지금 기본값과 접촉률·점수 비교 (발표 핵심 근거).
5. 최적이 범위 끝에 나오면 범위를 넓혀 다시 실험한다.
6. 샌딩도 같은 방식: `train.py sanding_<step> clay` (입력 이름이 다르면 `FEATURES`·SQL의 params 키만 바꾼다).

## 4. 검증 기록

- 가짜 데이터(최적 fz=-10, vel=50, 27개)로 `fit_surface`와 `main` 전체 실행 → 최적 (-10.0, 50.0), LOO R² 0.96. Windows Python 3.12, scikit-learn 1.9.1.
- 서버 PC(실제 DB, Ubuntu의 python3-sklearn)에서는 아직 안 돌려봤다.
