## 2. 적용 단계

> 이 폴더의 `files/`에 바꾸거나 새로 만든 파일이 모두 있다 (setup.py·package.xml·CMakeLists.txt는 현재 저장소 파일에 줄만 추가한 버전). 한 번에 적용하려면:
>
> ```bash
> W=/c/Users/adg61/Desktop/Claude_code/work18_협동1_매니저_통합/files
> R=/d/Rokey/rokey_team_ai_workspace/협동-1_ROS2_자동화공정
> cp -r "$W/rokey1/." "$R/rokey1_ws/"
> cp -r "$W/rokey_interfaces/." "$R/rokey_interfaces/"
> ```
>
> 아래 2-1~2-5는 같은 내용을 단계별로 적은 것이다.

### 2-1. 없는 파일 9개 복사 (`__pycache__` 제외)

```bash
cd /d/Rokey/rokey_team_ai_workspace/협동-1_ROS2_자동화공정
for f in config/robot.yaml utils/config.py utils/db.py utils/force_stats.py \
         utils/singularity.py utils/camera_up.py db/migrate_02.sql \
         launch/manager.launch.py; do
  mkdir -p rokey1_ws/$(dirname $f)
  cp work/files/rokey1/$f rokey1_ws/$f
done
# train.py 는 이 폴더의 수정본을 쓴다 (모델_계획.md 참고)
mkdir -p rokey1_ws/analysis
cp "/c/Users/adg61/Desktop/Claude_code/work18_협동1_매니저_통합/files/rokey1/analysis/train.py" rokey1_ws/analysis/
```

### 2-2. rokey_interfaces

- `work/files/rokey_interfaces/action/Process.action` → `rokey_interfaces/action/Process.action` 복사
- `rokey_interfaces/CMakeLists.txt`: `"action/ToolTask.action"` 다음 줄에 추가

```cmake
  "action/Process.action"
```

### 2-3. setup.py — 두 줄만 추가

`console_scripts` 끝에 넣는다. launch 파일은 기존 `glob('launch/*.launch.py')`로 자동 설치된다.

```python
            # ===== manager =====
            'manager = manager.manager:main',
            'fake_process = manager.fake_process:main',
```

### 2-4. package.xml — 두 줄만 추가

```xml
  <exec_depend>python3-yaml</exec_depend>
  <exec_depend>python3-pymysql</exec_depend>
```

### 2-5. 모듈화 정리 (선택)

- `리팩터링.md` 5장 참고 (파일 6개 교체, 삭제 제안 4개)

### 2-6. work 폴더 정리 (팀 확인 후)

- 적용 후 `work/files/`는 `rokey1_ws`와 중복이다. 문서는 이 폴더에 있으므로 `work/`를 지울지 정한다.

## 3. 검증 (로봇/서버 PC, Ubuntu)

```bash
cd ~/ws_cobot_pjt/ws_dsr
python3 -m py_compile src/rokey1/utils/*.py src/rokey1/manager/*.py src/rokey1/analysis/train.py
colcon build --packages-select rokey_interfaces rokey1
source install/setup.bash
ros2 interface show rokey_interfaces/action/Process
sudo mysql < ~/ws_cobot_pjt/ws_dsr/src/rokey1/db/migrate_02.sql   # 한 번만
ros2 launch rokey1 manager.launch.py fake:=true
# 다른 터미널: START INSERT → command DONE, task_log 6줄 확인
```

## 4. 주의

- `utils/config.py`는 `~/ws_cobot_pjt/ws_dsr/src/rokey1/config/robot.yaml`을 읽는다. PC에서 폴더 이름이 `rokey1_ws`면 못 찾는다 → 폴더 이름을 `rokey1`로 하거나 `ROKEY_CONFIG` 환경변수 지정.
- 기존 `hmi/hmi_server.py`의 `/api/estop`과 새 rosbridge `/estop`(매니저) 경로가 따로 있다. 연결 여부는 팀 결정.
